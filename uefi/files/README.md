# UEFI platform files

The riva platform directory is intentionally not populated with guessed Mu-Silicium source files yet.

Expected destination after the package format is confirmed:
`Platforms/Xiaomi/rivaPkg/`

The package must be authored against the pinned Mu-Silicium revision used by the HakiOS UEFI repository. Do not copy the redwood/SC7280 DSC/FDF or driver list and merely rename it.
